# teleosofisk — the Institute website

Source for **instituteofteleosophy.org** (English) and **teleosofiskinstitutt.no** (Norwegian).
GitHub: **BareHansen/teleosophy** · local folder: `~/Code/teleosofisk`

Both domains serve the same files from `~/www/` on the Domeneshop web hotel. The wiki
(meta-epistemology.org) lives beside it in `~/www/wiki/` and has its own repository,
**BareHansen/meta-epistemology** (`~/Code/meta-epistemology`). This repository never touches it.

## Layout

| Path | What it is |
|---|---|
| `public/` | **Exactly what is published.** Everything here is copied to `~/www/` on the server. |
| `public/index.html`, `public/no.html` | English and Norwegian page — generated by `build.py`, do not edit by hand |
| `public/styles.css`, `public/site.js` | Layout and the WebGL figure (edit directly) |
| `public/images/` | `mark.svg` (icon), `horizon.jpg` (landing landscape), `horizon-data.js` (local preview only, not uploaded) |
| `source/index.html`, `source/no.html` | The original pages; the long-form prose is taken from these |
| `source/.htaccess`, `robots.txt`, `sitemap.xml` | Copies of server files that are **not** deployed automatically |
| `build.py` | Generates the two pages in `public/` from `source/` plus the short texts defined in the script |
| `LENS.md`, `CONTEXT.md`, `CLAUDE.md` | Conceptual and editorial reference — read before changing copy |
| `design/` | Logo and landscape sketches, old logo |
| `deploy.sh` | Manual fallback for publishing |

## Changing the site

1. Edit `build.py` (headings, short texts, structure) or `source/*.html` (prose),
   or `public/styles.css` / `public/site.js` directly.
2. If you changed `build.py` or `source/`: `python3 build.py` (needs `pip3 install beautifulsoup4`).
3. Preview: open `public/index.html` in a browser.
4. Publish: commit and push to `main`.

## How publishing works

`.github/workflows/deploy.yml` runs on every push to `main` that changes `public/`. It:

1. backs up the live files on the server to `~/backups/teleosofisk-<timestamp>/`,
2. copies `public/` to `~/www/` over SSH (adds and overwrites, never deletes),
3. checks that both domains answer.

It never touches `~/www/wiki/`, `.htaccess`, `robots.txt` or `sitemap.xml`.
Progress and logs: the **Actions** tab on GitHub. It can also be started by hand there
("Deploy" → "Run workflow"). `.github/workflows/css-lint.yml` checks `public/styles.css`.

### One-time setup (two repository secrets)

```bash
source ~/.config/meta-epistemology/server-credentials
printf %s "$SSHPASS" | gh secret set DOMENESHOP_SSH_PASSWORD -R BareHansen/teleosophy
ssh-keyscan login.domeneshop.no | gh secret set DOMENESHOP_KNOWN_HOSTS -R BareHansen/teleosophy
```

(Or add them by hand under Settings → Secrets and variables → Actions.)

### Rolling back

Either revert the commit and push, or copy a backup back on the server:
`cp -p ~/backups/teleosofisk-<timestamp>/* ~/www/`.
